# Incident Handler's Journal — Ransomware Incident

## Overview
Completed as part of the Google Cybersecurity Professional Certificate.

This activity focused on documenting and analyzing a simulated ransomware incident affecting a healthcare organization using an incident handler's journal.

## Tasks Completed
- Documented the incident using the **5 W's** (Who, What, When, Where, Why).
- Identified phishing as the initial attack vector.
- Analyzed the impact of ransomware on critical files and business operations.
- Recorded observations and questions for further incident investigation.

## Key Findings
Attackers used phishing emails containing malicious attachments to gain access to the organization's systems and deploy ransomware, encrypting critical files and disrupting healthcare operations.

## Skills Demonstrated
- Security Incident Documentation
- Incident Analysis
- Phishing and Ransomware Awareness
- Incident Response Fundamentals
- Security Investigation Reporting

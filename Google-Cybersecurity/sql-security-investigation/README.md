# SQL Practical Labs

**Course:** Google Cybersecurity Professional Certificate  
**Module:** Tools of the Trade: Linux and SQL

## Overview

Completed practical SQL labs using a MariaDB database, focusing on data retrieval, sorting, filtering, and analyzing security-related information. Practiced investigating login attempts, identifying employee devices requiring updates, and retrieving relevant records using SQL operators.

## Completed Labs

### 1. Perform SQL Queries

- Retrieved employee device information from database tables.
- Selected specific columns to identify operating systems, email clients, and patch dates.
- Examined login records to investigate potentially unusual activity.
- Sorted login attempts by date and time.

**SQL Keywords:** `SELECT`, `FROM`, `ORDER BY`

### 2. Apply Basic Filters to SQL Queries

- Retrieved device IDs and operating systems from the machines table.
- Identified machines running a specific operating system that required updates.
- Filtered employees by department.
- Identified employees in specific offices and buildings.
- Used pattern matching to retrieve records based on office locations.

**SQL Keywords:** `SELECT`, `WHERE`, `LIKE`, `%`

### 3. Apply More Filters to SQL Queries

- Filtered login attempts based on specific dates.
- Retrieved login records within a specified date range.
- Investigated login attempts occurring at a specific time.
- Retrieved individual login records using unique identifiers.
- Practiced using comparison operators to narrow search results.

**SQL Operators:** `=`, `>`, `>=`, `<`, `<=`, `BETWEEN`

### 4. Filter with AND, OR, and NOT

- Identified unsuccessful login attempts occurring after business hours.
- Retrieved login attempts from specific dates associated with a potential security incident.
- Filtered login activity originating outside Mexico.
- Identified Marketing employees located in the East building.
- Retrieved employee information from the Finance and Sales departments.
- Excluded employees in the IT department to identify devices requiring updates.

**SQL Operators:** `AND`, `OR`, `NOT`, `LIKE`, `%`

## Skills Practiced

- SQL data retrieval and filtering.
- Security log analysis.
- Date and time-based filtering.
- Pattern matching.
- Investigation of failed login attempts.
- Employee and device information retrieval.
- Supporting security investigations through database queries.

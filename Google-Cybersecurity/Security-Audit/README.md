# Security Audit – Botium Toys

## Overview

This project was completed as part of the Google Cybersecurity Professional Certificate.

The objective was to conduct an internal security audit for the fictional company Botium Toys by reviewing its existing security controls, identifying gaps, and assessing compliance with relevant security standards and regulations.

## Activities

- Reviewed the organization's scope, goals, and risk assessment.
- Assessed existing security controls and identified missing controls.
- Evaluated compliance with PCI DSS, GDPR, and SOC requirements.
- Identified security and compliance gaps.
- Provided recommendations to improve the organization's security posture.

## Key Areas Assessed

- Access control and least privilege
- Password policies and password management
- Network security controls
- Intrusion detection
- Data encryption and backups
- Disaster recovery
- Physical security controls
- PCI DSS compliance
- GDPR compliance
- SOC controls
